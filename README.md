# Pedestrian Living Hell · 行人地獄

Version 2.0 follows a fictional breakfast run through three Taiwanese street scenes. Steer with the arrow keys, WASD, or the touch controls. Release to stop. Press P or Escape to pause. A collision restarts the current block after confirmation. English and Traditional Chinese are available.

Open `index.html` locally or serve the directory with any static web server. The game uses Canvas 2D, original generated background artwork, and optional synthesized audio. No build or external runtime is required.

Inspired by [Wayne Chang’s December 2022 CNN Travel reporting, syndicated by KESQ](https://kesq.com/entertainment/cnn-style/2022/12/05/taiwans-living-hell-traffic-is-a-tourism-problem-say-critics/). The routes and traffic patterns are fictional.
